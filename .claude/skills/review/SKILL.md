# Review

대상: $ARGUMENTS (없으면 `git diff`로 변경된 파일)

## 순서
1. 대상을 **`reviewer` 에이전트**에 넘긴다 (구현한 맥락과 분리된 시선으로 검토)
2. 결과를 🔴 필수 수정 / 🟡 권장 / 💡 제안으로 정리
3. `src/<기능>/TODO.md`에 기록
   - 🔴 → NOW 섹션에 작업으로 추가
   - 🟡 💡 → 리뷰 기록 섹션에 날짜와 함께
4. 🔴가 있으면 수정 후 다시 리뷰
