# Review

대상: $ARGUMENTS (없으면 `git diff HEAD`와 새 파일)

## 순서
1. 대상을 **`reviewer` 에이전트**에 넘긴다. 구현 맥락은 넘기지 않고 SPEC.md 경로와 변경 목록만 준다 (분리된 시선)
   - reviewer가 보고서를 넘기면(SubagentHandback) 훅이 `승인 가능 여부:` 줄을 읽어, **승인일 때만** 리뷰한 코드의 해시를 `.claude/state/review.json`에 기록 → 이 해시가 지금 코드와 같아야 커밋 가능
   - reviewer에게 마지막 줄을 `승인 가능 여부: ✅ 승인` 또는 `승인 가능 여부: ❌ 수정 후 재검토`로 쓰게 한다 (줄이 없으면 거절로 처리)
2. 결과를 🔴 필수 수정 / 🟡 권장 / 💡 제안으로 정리
3. `src/<기능>/TODO.md`에 기록
   - 🔴 → NOW 섹션에 작업으로 추가
   - 🟡 💡 → 리뷰 기록 섹션에 날짜와 함께
4. 🔴를 고쳤으면 코드가 바뀌었으니 **다시 리뷰** (반영 여부는 PR 본문에 남김, Phase 3)
