# 버전 bump SPEC
> 상태: **승인됨 (agent:build, 이슈 #17)**
> 이슈: #17

## 왜 (문제)
릴리스 노트를 쓸 때 다음 버전 번호를 손으로 계산한다. 규칙을 함수로 고정해 실수를 없앤다.

## 무엇을 (요구사항)
- `MAJOR.MINOR.PATCH` 문자열과 올릴 부분(`major`·`minor`·`patch`)을 받아 다음 버전 문자열을 돌려주는 함수 `bump(version, part)`를 제공한다.
- 올린 자리보다 아래 자리는 0으로 초기화한다.
- 위치: `src/` 아래 새 모듈, 테스트는 `tests/` 아래.

## 인수조건 (테스트로 옮겨질 문장)
- [ ] `bump("1.4.2", "minor")`일 때 `"1.5.0"`이다
- [ ] `bump("1.4.2", "major")`일 때 `"2.0.0"`이다
- [ ] `bump("1.4.2", "patch")`일 때 `"1.4.3"`이다
- [ ] `bump("0.0.0", "patch")`일 때 `"0.0.1"`이다 (경계값: 0)
- [ ] `bump("1.9.9", "minor")`일 때 `"1.10.0"`이다 (각 자리는 9를 넘어도 허용)
- [ ] 버전이 `"1.2"`, `"1.2.3.4"`, `"a.b.c"`, `""`, `"1.2.-3"`일 때 `ValueError`다
- [ ] 접두사(`"v1.2.3"`)·pre-release(`"1.2.3-rc.1"`)·build 메타(`"1.2.3+sha"`)가 붙은 버전일 때 `ValueError`다
- [ ] 부분 이름이 `"Minor"`, `"build"`, `""`처럼 알 수 없는 값일 때 `ValueError`다

## 범위 밖
- 접두사(`v1.2.3`), pre-release·build 메타데이터(`-rc.1`, `+sha`) 처리
- 하네스 연결

## 결정 (질문의 제안대로)
1. 위치: `src/versioning/bump.py`, 테스트 `tests/test_versioning.py`.
2. `"01.2.3"`처럼 앞자리 0이 있는 숫자는 `ValueError`. 출력은 앞자리 0 없는 정수.
3. 부분 이름은 정확히 소문자 `major|minor|patch`만 허용, 그 외 `ValueError`.
4. 숫자 범위 제한 없음. ASCII 숫자 `0-9`만 허용(전각 숫자 등은 `ValueError`).
5. 문자열이 아닌 입력(`None`, 정수)은 `ValueError`로 통일.
