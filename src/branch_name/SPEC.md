# branch-name SPEC
> 상태: 승인됨 (agent:build, 이슈 #11)
> 이슈: #11

## 왜 (문제)
`ship` 스킬이 브랜치 요약(slug)을 매번 모델이 지어서 형식이 들쭉날쭉하다. 규칙을 순수 함수로 고정해 같은 입력이면 항상 같은 이름이 나오게 한다.

## 무엇을 (요구사항)
- 이슈 번호(int)와 제목(str)으로 `agent/<번호>-<slug>` 형식의 브랜치 이름을 만드는 함수를 제공한다.
- 위치: `src/branch_name/` 모듈, 테스트 `tests/test_branch_name.py`. 함수 이름은 `make_branch_name(number, title)`.
- slug 규칙: ASCII 영문·숫자만 남기고 소문자화 → 나머지는 구분자로 보고 연속된 구분자를 하이픈 하나로 → 앞뒤 하이픈 제거 → 최대 30자(하이픈 경계에서 절단) → 비면 `issue`.

## 인수조건 (테스트로 옮겨질 문장)
- [x] (12, "Add login page")일 때 `agent/12-add-login-page`다
- [x] 대문자가 섞인 제목("Fix API Bug")일 때 slug가 소문자(`fix-api-bug`)다
- [x] 제목에 숫자가 있으면("Bump v2 to 3") 숫자는 유지된다(`bump-v2-to-3`)
- [x] 영문·숫자가 아닌 문자가 연속("a  --  b!!c")일 때 하이픈 하나로 합쳐진다(`a-b-c`)
- [x] 제목 앞뒤가 구분자("  !!hello!!  ")일 때 앞뒤 하이픈이 없다(`hello`)
- [x] 한글이 섞인 제목("로그인 login 버그")일 때 한글은 구분자로 취급되어 `login`이다
- [x] 한글만 있는 제목("로그인 버그")일 때 slug는 `issue`다
- [x] 빈 문자열·공백·기호만("", "   ", "!!!")일 때 slug는 `issue`다
- [x] slug가 30자 이하일 때 그대로 둔다(정확히 30자 경계 포함)
- [x] slug가 30자를 넘고 30자 안에 하이픈이 있을 때 단어 중간이 아니라 30자 이내 마지막 하이픈 앞에서 자른다(결과 ≤ 30자, 끝이 하이픈이 아님)
- [x] 31번째 문자가 하이픈이어서 앞 30자가 단어 경계에서 끝날 때 앞 30자를 모두 유지한다
- [x] 결과 slug는 어떤 입력에서도 `[a-z0-9-]`만 쓰고 30자 이하이며 앞뒤·연속 하이픈이 없다
- [x] 번호가 0 또는 음수일 때 `ValueError`다
- [x] 같은 입력을 두 번 넣으면 같은 결과다(순수 함수, 외부 I/O 없음)

## 범위 밖

- LLM 호출 (결정적 코드이므로 평가 기준 없음)

## 결정 (소유자 — 질문 5개 모두 제안대로)
1. 30자 제한은 slug에만 적용한다 (`agent/<번호>-` 접두사 제외)
2. 하이픈 경계가 없으면(첫 단어가 30자 초과) 30자에서 자른다
3. ASCII 영문·숫자만 남긴다 ("café" → `caf`)
4. 번호는 0 이하일 때만 `ValueError`. bool·int 아닌 값은 다루지 않는다
5. `src/branch_name/`, `make_branch_name(number, title)` 그대로
